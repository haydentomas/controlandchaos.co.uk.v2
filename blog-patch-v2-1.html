Patch Notes: Cloud KVP Memory Optimization

Performance enhancements across all sim terminals and venue bridges to eliminate script delay during peak club hours.

Sim-Wide Engine Upgrade v2.1

All terminal scripts, tribute adapters, and titler endpoints across Control & Chaos have been refactored for maximum region performance during high-capacity events.

Changes & Optimizations

  • LinksetData Memory Caching: Replaced synchronous HTTP database lookups with native LinksetData key-value caching.
  • Asynchronous Experience KVP Backing: Profile stats and XP totals now commit asynchronously in the background, eliminating script execution pauses.
  • Memory Audits: Over 25KB free memory per module with zero region time dilation, even during 50+ avatar club events.
